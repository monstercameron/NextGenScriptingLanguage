# Hosted Linux result

This directory preserves one completed hosted Linux x86_64 run of the fixed literal-argument `runtime::run` microbenchmark: GitHub Actions run `38862234332`, attempt 1. The run completed all 102 invocations: 3 warmup pairs followed by 48 measured pairs, alternating AB/BA order, with 3 raw samples per invocation. Independent recomputation gives **48 candidate-faster pairs, 0 slower pairs, 0 ties**, median paired candidate-minus-baseline **−165,905.5 ns**, median pairwise candidate/baseline ratio **0.8265255155**, and ratio of arm medians **0.8279160252**. Every attempt passed the raw correctness oracle, with exact output `b"3"`, 1,000 completed in-process calls, and zero runtime-reported child launches. No retries were observed.

The timer excludes workload parsing, registry loading, runtime options construction, test-process startup, and report serialization. It includes runtime validation/execution of 1,000 in-process `core.number_add` calls. This is a fixed public `runtime::run` microbenchmark, not a graph queue test or an end-to-end application measurement.

The run used Ubuntu 24.04 on an x86_64 GitHub-hosted runner; the retained kernel is `6.17.0-1022-azure`. The CPU model was not recorded. Workflow and benchmark sources are preserved under `source/checked-in-at-dispatch/` from dispatch commit `278541e7d9a88bc55058ca133b3031675dfb84d0`; measured arm patches reconstruct source base `b824aeaa7bccaa4d3d75d3fc6a363a99138287d4`. Both arms used separate fresh release targets and were built once. Source identity remained stable; the independent audit verified distinct saved binary hashes.

Executable bytes are omitted from this source-only publication. Their SHA-256 hashes and sizes are listed in `excluded-executables.json` and recorded in original build receipts and the independent audit; the original hosted CI artifact/local download retains the bytes.

`evidence/` retains the preregistration, exact request, all 102 raw attempt folders and sidecars, paired report, run status, source freeze, patches, build receipts/logs, source-stability checks, and independent audit. `source/source-manifest.json` verifies the exact dispatch source files and product patch bytes. The audit and raw report are not collapsed into the adjacent Darwin result; see the parent README for separate platform results. No result is pooled across systems, and this single run does not establish a general speedup.
