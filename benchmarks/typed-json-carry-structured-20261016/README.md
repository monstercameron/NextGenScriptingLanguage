# Typed JSON carry: structured CSV trial

**Publication status: frozen, adversarial review passed.** The measured change was subsequently integrated in local commits `97df47ce127b97149306ba9f3e3dfd24c9712681` and `c719653b52dcfa54db541763721391dba3c9a00c`, on a newer base than this experiment. The structured trial is positive for its narrowly defined workload; it does not establish general runtime performance. The `evidence/typed-json-carry-structured/README.md` and `root-trial-summary.json` are preserved pretrial/pre-audit records: the former still says no timing has run and the latter says `raw_audit_pending`. The final audit report below supersedes those status statements; both original files remain byte-for-byte preserved for history.

## Result

This fixed public-runtime trial measured 1,000 uncached, in-process `csv.parse` calls over the same 4,063-byte CSV with 64 rows and 4 columns. The DSL requires distinct result names, so all 1,000 parsed result tables remained live through the run. The final table was encoded as compact JSON. Setup, CSV/program construction, registry loading, hashing, report writing, and `RunResult` destruction were outside the timed interval.

Across 48 preregistered measured AB/BA pairs, the candidate won all 48. The median paired candidate/baseline ratio was **0.7371399229**, equivalent to about **26.3% lower** time for this case, with median paired delta **−14,221,270.5 ns** (exact median; the paired runner report stores the truncated integer). Median invocation durations were **54,809,833.5 ns** baseline and **40,102,312.5 ns** candidate. All 102 attempts (three warmup pairs plus 48 measured pairs) succeeded with no retries; all raw and semantic oracles passed.

This result must be read alongside the separate [scalar `number.add` trial](../typed-json-carry-scalar-mixed-20261016/README.md), which had 27 wins and 21 losses, a median paired ratio of 0.97568, and order-dependent direction (AB worse, BA better). The structured result does not erase or combine with that mixed scalar result. Together they show that the measured effect depends strongly on workload shape. Do not pool the percentages or generalize the structured result to CLI startup, default catalog loading, or ordinary runtime programs.
