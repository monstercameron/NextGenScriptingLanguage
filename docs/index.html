01 / THE IDEA

Keep the tools.
Upgrade the glue.

/bin

Unix does the work.

Call cat, git, jq, gh or any installed executable directly. Named applet manifests are optional adapters.

.program

The script owns the flow.

Inputs, branches, pipes and events stay visible. check --json, explain --json and --what-if show the plan before anything runs, to a person or a model. AI results return as data; your program chooses the next action.

→ →

Rust keeps it moving.

Native OS pipes, supervised child processes, bounded captures, checkpoints that resume a repaired script, and an optional warm daemon for repeated runs. No per-app compilation step.

05 / THE NUMBERS, WITH RECEIPTS

Honest numbers.
Bash still wins the basics.

2 of 8

scenarios where Execute
is ahead of Bash.

On a Linux x86_64 runner Execute wins a 1000-iteration loop of builtin calls (2.80 vs 4.37 ms) and, marginally, a loop of 100 process spawns (63.86 vs 67.07 ms).

Execute loses startup (1.76 vs 1.20 ms), binary size (7.16 MB vs 1.45 MB) and memory (6.2 MB vs 3.4 MB peak at startup). Optimisation is ongoing.

Build the source candidate

Requires a Rust toolchain and the native tools used by your script. The default build is lean; add --features full for the terminal UI, live control and the language server.

git clone https://github.com/monstercameron/NextGenScriptingLanguage.git
cd NextGenScriptingLanguage
cargo build --locked --release
printf 'hello\nworld\n' > input.txt
./target/release/execute examples/direct.program

REAL POWER. REAL BOUNDARIES.

Execute is aiming at a complete, observable Unix scripting language. It is not yet a Bash replacement and not a certified Omarchy replacement. Current source is 0.9.0-rc.5: it adds loops, background jobs, the warm daemon, per-element checkpoints and a security pass tracked in the threat model, none of it in a release yet. Jobs that outlive their script, terminal ownership beyond one command, and real desktop acceptance remain open. The published release candidate is 0.9.0-rc.4. The historical repository binary remains 0.8.0.
