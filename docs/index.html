01 / THE IDEA

Keep the tools.
Upgrade the glue.

/bin

Unix does the work.

Call cat, git, jq, gh or any installed executable directly. Named applet manifests are optional adapters.

.program

The script owns the flow.

Inputs, branches, pipes, components and events stay visible. AI results return as data; your program chooses the next action.

→ →

Rust keeps it moving.

Native OS pipes, supervised child processes, bounded captures, checkpoints and local live-state control. No per-app compilation step.

REAL POWER. REAL BOUNDARIES.

Execute is an evolving Unix glue language, not a certified Bash drop-in or a complete Omarchy replacement. Loops, jobs, external modules, richer redirection and real desktop acceptance remain open. Packaged 0.8.0 and source 0.9.0-dev have different capabilities.
